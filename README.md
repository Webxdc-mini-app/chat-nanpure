# ちゃっとナンプレ 1.3.2

DeltaChatのグループで、一つの盤面をみんなで解くwebxdcアプリです。数字・候補メモ・相談コメントを共有し、後から開いた人も届いている更新履歴から続きを再開できます。

対象ファイル：chat-nanpure-1.3.2.xdc

## はじめ方

1. DeltaChatで、一緒に遊ぶグループを開きます。
2. 一人が chat-nanpure-1.3.2.xdc を添付して送信します。
3. 全員が、その**同じ添付**からアプリを開きます。
4. 読み込みが終わったら、空きマスをタップして数字を入力します。
5. 盤面の下の「みんなで相談」で、気づきやヒントを話し合います。

ファイルを別のメッセージで送り直すと、別のゲームになります。続きは最初に遊んだ同じ添付から開いてください。

## 図入り操作マニュアル

- [HTML版](chat-nanpure.html)：図を埋め込み済み。HTML単体で開けます。

画面図は実装のボタン名と配置に合わせた説明図で、実機のスクリーンショットではありません。

## 画面配置

幅420px以下では「メモ・消去・ヒント・チェック」が2列×2段に並びます。広い画面では横一列です。操作方法は同じで、チェックが枠からはみ出さないよう調整しました。

## 操作の早見表

| やりたいこと | 操作 |
|---|---|
| 数字を入れる | マスを選択 → メモOFF → 1〜9 |
| 修正する | 同じマスを選び、別の数字を入力 |
| 消す | マスを選択 →「消去」または「×」 |
| 候補をメモする | メモON → 候補の数字。同じ数字を再度押すとその候補を解除 |
| ヒントを使う | 「ヒント」。選択中の未正解マスを補助し、対象外なら別の未正解マスを選択 |
| 正誤を確認する | 「チェック」。入力済みの数字の正誤を文章で表示 |
| 効果音を切り替える | 「効果音 ON／OFF」。自分の端末だけに適用 |
| 相談する | 500文字以内で入力 →「送信」 |
| 呼びかける | 相手一覧から「@名前 」を挿入して送信 |
| 変更を確認済みにする | 「確認済みにする」 |
| 新しい問題を始める | 「あたらしい問題」または難易度 → 確認 |
| 完成画像を共有する | クリア後に共有ボタン → DeltaChat側で送信先を確認して送信 |

数字の入ったマスでメモ入力すると、大きい数字が候補メモに置き換わります。候補の自動整理や「元に戻す」はありません。

## 共同プレイの機能

- **共有と復元**：数字・メモ・コメントを共有します。同じマスの同時編集は、アプリ内の競合処理で一つの表示に揃えます。
- **コメント**：名前・日時付き。問題を変えても残り、画面には最新200件を表示します。編集・削除はできません。
- **開始・完成の案内**：DeltaChatのチャットに短い案内を送ります。
- **変更ハイライト**：アプリを離れたときと比較し、ほかの人が編集したマスを黄色枠で表示します。初回など保存データがない場合は比較表示しません。
- **@名前の通知**：名前の後ろに空白か句読点を入れます。同名の相手は全員が通知先になります。相手一覧は参加履歴から作ります。
- **貢献度とMVP**：現在の正しい数字を最後に入力した人へ1マスを加算します。最初の数字とヒントは除外。同点は全員MVPです。
- **完成画像**：PNGとMVPの文章をDeltaChatの送信画面へ渡します。自動送信はしません。
- **カーソル共有**：対応環境で、開いている相手の選択マスに名前を表示します。15秒間更新がないカーソルは消えます。履歴には保存しません。

## パソコンのキー操作

- 1〜9：数字入力
- 0、Delete、Backspace：消去
- 矢印キー：マスを移動
- m：メモ切り替え
- コメント欄のEnter：改行
- コメント欄のCtrl+Enter：送信。MacではCommand+Enterも利用可能

コメント入力中は、数字キーなどで盤面は変わりません。

## 1.3.2のクリア後の操作

クリア画面の「つぎへ」は、確認画面なしで同じ難易度の次の問題へ進みます。「あたらしい問題」や難易度から途中で切り替える場合は、アプリ内の確認画面で「切り替える」を押してください。「やめる」で取り消せます。どちらも全員の盤面に影響します。

## 新しい問題について

難易度は「かんたん」「ふつう」「むずかしい」。端末内で生成し、解が一つになるよう確認します。難易度は主に最初の数字の数による区分で、解法の高度さを厳密に評価したものではありません。

問題を変えると**全員の盤面・メモ・貢献度をリセット**します。コメントは残ります。前の盤面へ戻せません。

## 通信と対応環境

webxdcを開けるDeltaChatをご利用ください。盤面・コメントの反映速度は通信状況に依存します。オフラインの変更は相手へすぐ届きません。通知表示はDeltaChatの対応状況・通知設定に依存します。画像共有やカーソル共有は対応APIがある環境で利用でき、未対応の場合はアプリ内に表示します。

アプリ内コメントは、DeltaChat本体の通常メッセージとは別です。本体の会話を自動取得しません。別の添付へ以前の盤面・会話を移す機能はありません。

## 困ったとき

| 状況 | 対処 |
|---|---|
| 相手と盤面が違う | 同じグループの同じ添付か確認し、通信を待ってから開き直す |
| 更新が届かない | 通信とグループへの送信権限を確認 |
| 自分の入力が変わった | 同じマスの同時編集の可能性。相談して修正 |
| 通知が見えない | 名前の後ろの空白・句読点、参加履歴、通知設定を確認 |
| カーソルが見えない | 対応環境で相手も開いているか確認。表示の消失は退出とは限らない |
| 画像を共有できない | クリア済みか、共有APIに対応しているか確認 |
| 送信失敗が表示された | 残っている文章を確認し、通信が戻ってから再送 |

## 確認状況

1.3.2ではブラウザ上の実ボタン操作で、クリアから次の問題への遷移を2回繰り返し、相手端末を模した画面への同期、問題変更の確認・キャンセル、難易度変更を確認しました。iPhoneのDeltaChat実機では未確認です。

問題生成・同時編集・履歴復元・コメント共有・通知データ・貢献度・MVP・カーソルデータ・画像共有APIのシミュレーション検証を実施済みです。生成した36問で一意解を確認しました。

DeltaChat実機での通知表示、PNG描画結果と送信画面、端末間リアルタイム通信は未確認です。

## 技術情報

xdc内は index.html、manifest.toml、icon.png で構成します。webxdc.js はDeltaChatが提供するため含めません。問題と効果音は端末内で生成します。

| API | 用途 |
|---|---|
| sendUpdate／setUpdateListener | 盤面・メモ・コメントと履歴の共有 |
| info／summary | 開始・完成の案内と概要 |
| notify／href | 特定参加者への通知と相談欄へのリンク |
| sendToChat | 完成PNGと文章の送信準備 |
| joinRealtimeChannel | 一時的なカーソル共有 |

[公式webxdc API仕様](https://webxdc.org/docs/spec/api.html)
